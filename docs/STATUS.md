# Publication status

## Included

- Project purpose and scope.
- Research and reporting principles.
- External source references and contribution guidance.

## Not available in this release

- Public model code, an installable package, or a reproducible benchmark.
- Raw or transformed baseball data, saved predictions, model weights, or evaluation outputs.
- A browser application, API, live feed, or deployed service.

The existing research implementation depends on private evaluation artifacts and environment-specific tooling. Publishing it responsibly requires a portable dependency setup, source-specific redistribution review, and independent validation using a distributable example. These are release requirements, not a delivery commitment.

Future claims about reproducibility or predictive performance should be accompanied by the exact published code version, a defined data-access procedure, a complete evaluation protocol, and relevant verification evidence.
