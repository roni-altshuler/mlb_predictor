# Contributing

This release accepts documentation feedback and methodological discussion. There is no public application to install or test yet.

For a documentation issue, identify the page and passage, explain the problem, and include a public supporting reference where appropriate. For a proposed research change, describe the hypothesis, required inputs, information-availability assumptions, and evaluation plan before proposing implementation.

Do not attach credentials, personal information, private evaluation artifacts, or datasets without verified redistribution rights. Link to a publisher's official source rather than uploading third-party data.

No contribution license agreement or project-wide open-source license is established by this release. Discuss licensing before submitting substantial code or third-party material.
